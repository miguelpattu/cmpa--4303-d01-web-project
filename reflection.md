# **Reflection**

## *Decisions*

The most important decisions I made during this project was selecting the content to use for the website, the format and flow, the overall design and what tools were used to assist with creating the website. 
The content I wanted to use for the website had to be informative and resourceful. Something that was useful and educational to the site visitor. The website was built with the intent of being on “one stop shop” for information and resources pertaining to German Shepherds. I wanted the format to be easy to follow by being able to find the topics using the navigation bar at the top but to also have some information in the home page. 

The main tools I used for the project were GitHub, Visual Studio Code, HTML skeleton and Gemini AI. GitHub was the main tool for creating the repository and files for creating the html codes. Visual Studio Code for debugging and testing, HTML skeleton to find the basic structure for certain commands and also do test runs. Gemini AI assisted with finding some errors and suggestions to make the page more efficient. 

## *What Worked*

What worked well was the basic structure of the home page, I also was able to embed videos into the home page which provide the user the ability to watch YouTube videos without leaving the website. I was most satisfied with the navigation bar; I was able to organize different topics and have them either lead to a different page within the site or move directly to the portion of the home page the information was located. 

## *What would you do differently*
If I could change my approach, I would have mapped out the website better before starting. I had the idea in my mind of what I wanted it to look like but not create a map or workflow and it felt like I was creating as I went along. I would have described the scope better and refined it along the way. 

## *What you learned*

What I learned about myself building this website over the semester was overcoming the fear of the unknown, learning how to be creative and building something from scratch. I was unaware how flexible and versatile html codes are, there are seemingly endless commands to make a website function and give it uniqueness to any other website. I was intimidated by some of the tools at the beginning but I was used them more, I got quite comfortable and html code pretty began to look like a normal language. I understood what the html tags meant without having to look them up on cheat sheet every time. One cool thing I learned was how to make the website fit properly on mobile devices.
